# Daily Mission Reward — GitHub Edition

Upload `index.html`, `style.css`, and `script.js` to a GitHub repository and enable GitHub Pages.

## Features
- Account creation and login
- Up to 10 custom missions
- Custom title, points, start/end time
- Upcoming/active/expired/completed status
- Complete missions only during their active time
- Edit/delete missions
- Points persist after browser close using localStorage
- Point history
- Custom final reward
- Reward claim only when enough points are available
- Small emoji mission character
- No PHP/MySQL required

## GitHub Pages
Repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

### Note
This is a browser-only demo. Data is stored in the current browser/device. For real multi-device accounts and server-side security, use a backend/database.
